# Game

The game this repo builds, grown one change at a time through the software factory.

## Language

**Game**:
The thing the Player plays; the product this repo builds.
_Avoid_: Counter, app, Factory Game

**Player**:
The person playing the Game.
_Avoid_: User, visitor

**Count**:
The number shown to the Player, starting at zero.
_Avoid_: Score, total

**Increment**:
The Player's one action, which adds one to the Count.
_Avoid_: Click, tap
